# Interactive CNV method guide

The [offline HTML guide](../../research/2026-10-29-low-coverage/interactive-guide/index.html)
explains all 36 records from the low-coverage research review, including CNV
callers, segmentation models, reference strategies, representations, count and
allele models, and technical priors. Each entry has an input-to-inference
walkthrough, a hypothetical worked example, primary sources, and a proposed
adaptation with missing prerequisites and a first experiment.

The page includes interactive teaching calculations, comparisons between up to
three entries, a workflow map, and a viewer for the existing descriptive
300-cell summaries. It opens directly from the filesystem and requires no
application server. The [guide README](../../research/2026-10-29-low-coverage/interactive-guide/README.md)
documents its controls, formulas, provenance and rebuild procedure.

This is educational research material. It adds no scientific feature to the
application and executes no CNV caller. Original method records, input data,
historical validation archives and production calculations are unchanged.
Published mechanisms, hypothetical calculations, proposed adaptations and
observed pilot summaries are explicitly distinguished. MCF10-A identity is not
used as a diploid or region-level CN label.
