Key findings

  1. Overall fit, 12 regions: clonal 5; subclonal 3; small-fraction deviation (<10% of cells) 3; no evidence 1 (bootstrap B = 99, so the smallest attainable p is 0.01).
  2. Regions with p < 0.05: chr7_8.3_10.7: loss1 14% [9%, 19%], p = 0.01, subclonal; chr7_51.4_53.5: amp 15% [12%, 19%], p = 0.01, subclonal; chr7_67.4_70.0: loss1 37% [29%, 48%], p = 0.01, subclonal; chr9_20_27: gain1 5% [4%, 5%], p = 0.01, small-fraction deviation (<10% of cells); chr9_22.5_26.6: gain1 5% [3%, 8%], p = 0.01, small-fraction deviation (<10% of cells); chr9_70_100: gain1 5% [3%, 4%], p = 0.01, small-fraction deviation (<10% of cells); lit_9p21_hemizygous_zone_approx: loss1 98% [98%, 98%], p = 0.01, clonal; lit_MYC_8q24: gain1 97% [96%, 98%], p = 0.01, clonal; lit_19q13_qter: gain2 100% [100%, 100%], p = 0.01, clonal; lit_5q13_qter: gain1 99% [99%, 100%], p = 0.01, clonal; chr8_115_145_cluster4_hypothesis: gain1 95% [95%, 96%], p = 0.01, clonal.
  3. Cluster-level fits (60 region x cluster tests, no multiplicity correction): 30 with p < 0.05.
  4. Empirical false positives in 30 uncalled random windows: p < 0.05 in 9/30 (30%; 95% CI 15%-49%); 'subclonal' 1/30 (3%; 95% CI 0%-17%); 'clonal' 6/30 (20%; 95% CI 8%-39%). Without the shared baseline offset: 16/30 (53%; 95% CI 34%-72%); depth term only: 21/30 (70%; 95% CI 51%-85%).
  5. Removing the allele term changes the best event type in 5/12 regions (median |change in pi| = 0.00); changing k from 0.6 to 1.0 changes the best type in 0/12.
  6. Without the shared baseline offset, 5 of 12 regions switch to a near-clonal (pi > 0.9) event that the primary model attributes to baseline: a baseline shift becomes an event unless it is modelled.
  7. Calibration: flank-relative baseline offset sd sigma_b = 0.45 (log), cluster term sd sigma_u = 0.034, genome-relative sigma_b = 0.50, from 120 uncalled random windows.

Question and why it matters

Experiments 15-17 chose observation models per modality, an orientation of alleles to major/minor haplotypes, and a region-level state grid. They treat each region as one unit. A subclonal event, however, is a statement about cells: what fraction of cells carry a state, in which clusters, and does the depth evidence agree with the allele evidence. This experiment puts the depth and allele observations of every cell into one mixture likelihood, estimates that fraction with an interval and a bootstrap p-value, and applies the same procedure to uncalled random windows so that the report states how often it would call a subclonal event where none is expected. It is an exploratory diagnostic for the evidence layer in recommendation.md, not a copy-number caller.

Inputs

  • AnnData raw counts (layers/raw), 3,460 cells x 25,337 bins; WNN clusters from the h5mu (sizes {'0': 1286, '1': 833, '2': 603, '3': 556, '4': 182}).
  • HA / HB / AT parquet joined by barcode name (checks: HA + HB = AT, coordinates and barcode set equal).
  • Exp 16 bin_orientation.tsv.gz (`all` and per-cluster groups) for major/minor orientation; exp 04 region definitions (build_regions).
  • 12 regions: the seven saved windows (six chr7/chr9 windows and chr9_70_100), four literature loci, and chr8:115-145 Mb (cluster-4 opposite-haplotype hypothesis from exp 16).
  • Calibration: 120 uncalled random 25-bin windows (baseline offset, cluster terms, background allele offset) and a disjoint panel of 30 for the false-positive rate, drawn from 12,197 eligible windows with seed (20261104, 18).
  • Not available: DNA truth, SNP-level phase sets, a technical baseline from unrelated samples.

Method

 (per region r, cell i; y = raw target count, N = AT on oriented bins, M = counts on the inferred major haplotype)
  cell state s_i in {0 = background 1:1, 1 = event e}, P(s_i = 1) = pi  (overall fit: one pi; cluster fits: pi_c),
  pi in [0.05, 1] under the alternative (an event must involve >= 5% of cells; smaller fractions cannot be told from cell-level outliers), pi = 0 under the null.
  depth     y_i | s ~ 0.99 NB2(mu_i * L_s, alpha_r) + 0.01 NB2(mu_i * L_s, 1)   (var = m + alpha m^2; the 1% broad component is an outlier-robust
            background for cell-level dropouts / spikes, a nuisance, not a state),  L_0 = 1.  alpha_r = region-specific dispersion by grid ML under
            the null (depth only; grid 0.003-0.15, exp 15 median 0.0199), held fixed afterwards.
            mu_i = E_i * (n_t / n_out) * exp(g_c) * exp(a_c),     E_i = raw total of cell i outside the region,
            n_t / n_out = target bins / bins outside the region.
            g_c  = cluster-c FLANK term (regions <= 100 bins, or the frozen saved flanks):  log[ sum_i in c F_i / (n_f/n_out * sum_i in c E_i) ]
                   i.e. mu uses the cluster's local flank rate;  g_c = 0 (genome-relative) for regions > 100 bins without frozen flanks.
            a_c = region baseline log ratio target/(flank or genome) in cluster c: a nuisance, a_c = b + u_c with
                   b ~ N(m, sigma_b^2) SHARED by all cells (the region's baseline offset, estimated jointly with pi),
                   u_c ~ N(0, sigma_u^2) per cluster; m, sigma_b, sigma_u are robust (median / 1.4826 MAD) summaries over
                   UNCALLED random 25-bin windows (calibration set, disjoint from the 30-window FPR panel).
            Because b is estimated jointly and penalised by the random-window spread, a homogeneous accessibility shift can be
            absorbed by b instead of masquerading as pi > 0; a shift larger than ~sigma_b still looks like an event.
  allele    M_i | N_i, s ~ BetaBinomial(N_i, h_s, rho_i),   rho_i = rho_r / N_i  (so overdispersion factor 1 + rho_r (N-1)/N saturates,
            consistent with exp 15's rho falling with AT and Pearson dispersion 1.27 -> 1.58 with AT; bin-level rho 0.0038 NOT reused).
            rho_r: maximum likelihood per region at the pooled h (grid), held fixed afterwards.
            h_0 = 0.5 + d0 ;  h_1 = clip(h_0 + k (h_e - 0.5)),  h_e = major-haplotype fraction of state e (exp 17 grid), k = attenuation.
            d0 = background major-fraction offset (orientation was chosen from the same counts, so h_0 > 0.5 even when balanced):
            nuisance, d0 ~ N(d_med, tau^2) with d_med, tau from the same uncalled random windows run through the same orientation rule.
            Cells with N_i = 0 contribute no allele term.  AT total itself is NOT modelled: conditioning on N_i removes the
            AT-depth dependence from the allele term; the residual dependence (depth and allele share fragments) is quantified by
            dropping the allele term (sensitivity).
  events    state e : (L_e, h_e)  : loss1 (0.5, 1.0)  homdel (0.02, 0.5)  cnloh (1.0, 1.0)  gain1 (1.5, 2/3)  gain2 (2.0, 0.5)  amp (2.5, 0.8)
            (L_homdel = 0.02, not 0, to allow background leakage; each type fitted separately; best type = highest penalised log-likelihood).
  orientation  bin oriented by exp 16 `all` posterior (B-major if p_B_major >= 0.5); only bins with certainty max(p, 1-p) >= 0.8 are used;
            M_i = sum of HB on B-major bins + HA on A-major bins.  Own-cluster orientation (exp 16 cluster groups) is only a descriptive column.
INFERENCE.  Penalised log-likelihood  l = sum_i log[(1-pi) f_0i + pi f_1i] - 1/2 (a-m)' S^-1 (a-m) - 1/2 ((d0-d_med)/tau)^2, maximised by L-BFGS-B with
  analytic gradients (a, d0, pi free).  Two starts per type (pi0 = 0.3 and 0.95, baseline shifted accordingly), best kept, same in data and bootstrap.
  Per-cell P(event) = pi f_1 / mix.  95% CI for pi: profile likelihood (grid 0.02, 2*dl <= 3.84).
  LRT_type = 2 (l_alt - l_null); T = max over the 6 types (selection included in the null).  p = (1 + #{T* >= T}) / (B + 1) from a PARAMETRIC
  BOOTSTRAP: y*, M* simulated from the fitted null (MAP a, d0; N, E fixed), refit with the identical pipeline; B = 99, PCG64 seed
  (20261104, 18, region_index) (random windows: region_index = 1000 + j).  Cluster fits (K = 1) use prior mean = mean of the overall null a-hat,
  sd sigma_u, and their own d_med / tau per cluster; their bootstrap p uses the same replicates (max over types per cluster).
CLASSIFICATION (prespecified).  p < 0.05: 'small-fraction deviation' if CI upper < 0.10 (about 350 cells: not interpreted as a subclone, such
  deviations are what a few percent of unusual cells produce); 'clonal' if profile CI lower bound >= 0.8; 'subclonal' if CI upper bound < 0.95 and lower > 0;
  otherwise 'event, clonal vs subclonal unresolved'.  p >= 0.05: 'no evidence' if CI upper <= 0.25, else 'insufficient evidence'.
  Clonal vs subclonal depends on the nuisance baseline: a clonal event whose depth change is within sigma_b is carried by the allele term only.
FPR.  30 uncalled random 25-bin windows (rule of exp 04 'random': consecutive retained bins, no gap; no called bin in the `all` karyogram),
  drawn with seed (20261104, 18), pushed through the same pipeline (own calibration windows excluded); empirical rate of p < 0.05 and of
  'subclonal event detected' / 'clonal'.
SENSITIVITY.  k in {0.6 primary, 1.0}; with vs without allele; depth removed (allele only); with vs without the shared baseline offset
  (offset removed = b fixed at m, so a baseline shift cannot be absorbed).

Limits and alternative explanations

  • Cluster accessibility differences mimic subclonal depth changes. The cluster term has sd sigma_u = 0.034 (flank-relative) estimated from random windows; a real accessibility difference between clusters at a region larger than that is, by construction, interpreted as an event in the clusters that differ. Cell types are not independent of copy number here (clusters may be partly clonal).
  • Allele-specific accessibility can shift the major fraction without any dosage change; k is not identified (0.6 vs 1.0 shown) and heterozygous-site ascertainment (exp 06/17) lowers allele information in hemizygous regions.
  • Phase uncertainty and circular orientation. Bins are oriented from pooled counts of the same cells, so even balanced regions have a major fraction above 0.5. The background offset d0 absorbs this with a prior from random windows; it is not a substitute for verified phase. Only bins with certainty >= 0.8 are used, and in the per-cluster fits the pooled `all` orientation can be wrong for a cluster (chr8:115-145 Mb, cluster 4).
  • AT is not independent of depth (both count fragments, exp 15). The allele term is conditional on AT, which removes the main dependence but not the shared fragments; the effect of dropping the allele term is shown in the Sensitivity section (best type changes in 5/12 regions; random-window false-positive rate 21/30 (70%; 95% CI 51%-85%) with depth only vs 9/30 (30%; 95% CI 15%-49%) joint).
  • Resolution floor. Events must involve at least 5% of cells (about 170 cells): a smaller fraction cannot be separated from cell-level outliers (doublets, dropouts). A broad outlier component (1%) is included in the background.
  • Prior calibration is conservative for large regions. The baseline spread comes from 25-bin windows; regions with hundreds of bins have a smaller true spread, so depth is down-weighted there. Windows are uncalled, not neutral.
  • Bootstrap scope. The parametric bootstrap holds alpha, rho, the exposure and the allele totals fixed; it does not propagate uncertainty in these nuisance parameters or in the orientation. With B = 99 the smallest p is 0.01. Cluster-level p-values are not multiplicity corrected.
  • MCF10-A is assumed to be 1:1 at the baseline; this is not verified here.
