Bottom line

A depth-only count changepoint with cell-sampling dispersion recovers every AD boundary within +/-2 bins but needs about 4155 segments on chr1-22 (AD: 164); with a structure-absorbing dispersion it needs 277 and recovers only 47 of 142 AD boundaries, so the count model does not resolve the segmentation question and its segment number is set by the dispersion choice, not by the data alone (exploratory, depth-only).

Key findings

  1. Dispersion estimated from the half split is close to Poisson (phi = 1.30 for all, 1.17 for cluster0), whereas first-difference dispersion is 861 and the Pearson-iterated phi is 1319-4037: bin-to-bin variation is overwhelmingly reproducible structure, not cell sampling.
  2. Segments on chr1-22 (source all): half-split phi 4203 / 4155 / 4084 for c = 1 / 2 / 5; Pearson phi 1077 / 277 / 55; AD 164. chr7: 245 (half-split, c=2), 15 (Pearson, c=2), 16 (AD).
  3. Agreement with AD at half-split phi, c = 2: 132/142 AD boundaries have a new boundary within +/-2 bins (142/142 within +/-5), but 4001 of 4133 new boundaries have no AD counterpart.
  4. Agreement at Pearson phi, c = 2: 47/142 AD boundaries matched within +/-2 (60 within +/-5); 95 AD-only and 208 new-only; at c = 5 only 55 segments remain and chr7 has none.
  5. The Pearson-phi iteration is unstable: starting from the one-segment dispersion, phi falls as segments are added and stops where the count stops changing, so the endpoint depends on c and on the start (phi 1319 / 2654 / 4037).
  6. Half-split stability (c = 2, chr1-22): 0.97 of 4133 half-split-phi boundaries and 1.00 of 255 Pearson-phi boundaries are found in both halves within +/-2 bins.
  7. Saved windows: at half-split phi every window edge has a boundary within +/-2 bins and 2-9 extra boundaries lie inside each window; at Pearson phi (c = 2) only the chr7_67.4_70.0 left edge (67.4 Mb) and chr7_70.0_73.3 right edge (73.3 Mb) coincide with a boundary and no candidate window has an internal boundary.
  8. Negative-binomial variant: alpha is estimated near zero (1.7e-05), segment counts match the Poisson ones within 1%, so NB changes nothing at this depth.

Question and why it matters

Method record B:2 (masked count changepoint with conditional alleles) proposes segmenting raw counts with an exposure term, explicit retained-grid gaps, zeros kept and relative rather than absolute states. This experiment implements only its depth part and asks whether such a count model gives boundaries consistent with the AD scan on the processed X pseudobulk, how many segments it needs, how that depends on the dispersion, and what it does at the saved target windows.

Decision informed: whether the recommendation should move from the AD scan on processed X to a raw-count changepoint (or add one as a cross-check).

Inputs

  • pyepi_results/count_matrix.h5ad, layers/raw: post-QC raw integer counts, 3,460 cells x 25,337 bins (100 kb), chr1-22 only used here. Units are counts per bin per cell; zeros kept.
  • Sources: all (3,460 cells) and cluster0 (1,286 cells; WNN labels via C.cell_clusters). Halves: C.stratified_halves(labels, (20261104, 11)) (all: 1729/1731 cells; cluster0: 643/643). Total exposures E: all 2.012e+08, cluster0 5.124e+07.
  • AD baseline: integration-story/data/genome_pool/raw_accepted_breakpoints.tsv (chromosome-local retained-bin index, checked against bp coordinates).
  • Gaps: retained grid from the h5ad; removed bins cross-checked with pyepi_results/binned_genome.csv. Windows: research/2026-10-29-low-coverage/shared/regions.tsv (part == target; 1-based starts).
  • Not available / not used: allelic (conditional-allele) emissions, per-bin mappability or GC covariates, per-cell models, an absolute ploidy reference, and any ground-truth copy number.

Method

  1. Per source sum the raw counts of member cells: yb; exposure E = total raw counts of those cells (constant over bins, so the rate is yb/E).
  2. Per chromosome, find the partition into segments of at least 5 retained bins minimising the penalised cost by exact optimal partitioning (O(n2)); breakpoints fall only between consecutive retained bins.
  3. Estimate dispersion phi (modes below), segment with phi, for c in {1, 2, 5} (prespecified, no search).
  4. Compare boundaries with the AD set (+/-2, +/-5 bins), rerun on each half, compute segment relative rates, flag gaps.
segment cost (Poisson, constants dropped)   C(S, m) = -S * log(S / m) / phi        S = sum y over segment, m = bins
penalised objective                        sum_segments C + beta * (#segments - 1),  beta = c * log(n_chrom)
NB variant (single alpha, r = 1/alpha)     C_NB(S, m) = -[ S*log(mu/r) - (m*r + S)*log1p(mu/r) ],  mu = S/m,  beta = c*log(n_chrom), phi = 1
half-split phi                              z2_b = (yA - n p)^2 / (n p (1-p)),  n = yA + yB,  p = E_A/(E_A+E_B);  phi = median(z2)/0.4549, bins with n >= 20
Pearson phi (iterated)                      phi = median((y - mu_seg)^2 / mu_seg) / 0.4549 ; start = one segment per chromosome ; repeat until segment count unchanged (max 12)
NB alpha (half split)                       alpha_half = sum[(yA - rho*yB)^2 - (muA + rho^2 muB)] / sum[muA^2 + rho^2 muB^2], winsorised 0.5/99.5%; alpha_full = alpha_half * cells_half / cells_full
segment relative rate                       rel = (S/m/E) / median over genome segments of (S/m/E);  95% interval rel * exp(+/- 1.96 sqrt(phi / S))

Parameters: minimum segment 5 bins; c in {1, 2, 5}; phi modes phi1, half_split, pearson, nb_half; halves seed tuple (20261104, 11); the segmentation itself is deterministic. phi is one genome-wide scalar per source. In half runs the parent's half-split phi is reused; Pearson phi is re-estimated per half; NB uses alpha_half.

Limits and alternative explanations

  • Constant exposure per source and no bin covariates (mappability, GC, accessibility); only a segment-constant level is modelled.
  • phi is one genome-wide scalar. Quasi-Poisson with reproducible bin structure is not a likelihood model; the Pearson phi absorbs structure and the half-split phi ignores it, so segment number depends strongly on the estimator. An intermediate, defensible dispersion was not identified here.
  • The penalty (c log n) and the c grid are conventions, not calibrated to a false-positive rate; no null calibration was run, so none of the boundaries carries an error-rate statement.
  • NB variant: moment alpha with a 1/#cells scaling assumption, segment mean S/m rather than the NB MLE.
  • One stratified split; half agreement tests cell sampling only. AD and this model differ in input (processed X versus raw counts), so differences mix method and normalisation.
  • Depth only: conditional-allele emissions of B:2 are not implemented. Alternative explanations for depth steps include accessibility, mappability/GC residuals, cell-cycle composition and dosage; they are not separated.

What the evidence supports

Supports

  • Every AD boundary on chr1-22 has a boundary within +/-5 bins in the raw-count model at cell-sampling dispersion, consistent with AD boundaries being steps in raw depth, not artefacts of the X processing.
  • Boundaries are reproducible across stratified halves, consistent with structure shared across cells rather than cell-draw noise.
  • Gaps can be handled explicitly with no change to the boundaries' positions beyond the retained grid.

Does not support / cannot tell

  • That the count model resolves segmentation: its segment number moves from tens to thousands with the dispersion estimator.
  • That the extra boundaries at cell-sampling dispersion are separate states: they follow reproducible bin-level structure for which no sampling model was fitted.
  • Any copy-number interpretation of relative depth; accessibility and dosage are confounded.
  • Calibration: no false-positive rate was measured for this changepoint.

Decision impact

For recommendation.md: the raw-count changepoint does not replace the AD scan. It adds support that AD boundaries are steps in raw depth (high recall at lenient dispersion), but it does not decide how many segments are justified, because the dispersion choice (not the data alone) sets that. Any adoption would first need a dispersion model that handles reproducible bin structure (for example a segment-level random-effect or autoregressive term) and a selection-aware null calibration comparable to experiment 05.

Next checks

  • Add a dispersion model for reproducible bin-level structure (e.g. NB with bin-level random effects fitted from replicate halves, or an AR(1) residual) and re-estimate phi without the unstable iteration.
  • Run a selection-aware null (permuted bins, as in experiment 05) through this changepoint at each setting to measure false-positive segment rates.
  • Add the allelic emission (B:2 conditional alleles) and test whether it separates depth steps AD finds from those it does not.
  • Repeat on additional random splits and the other WNN clusters to see whether boundary stability varies with split.
