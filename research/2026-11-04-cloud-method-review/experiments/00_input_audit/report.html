Bottom line

All 24 of 24 data-package files and 12 of 12 pinned pyEpi source files match their manifests, and the matrices are aligned by cell and bin, but 5 of 9 preprocessing stages (fragments, pre-QC counts, QC masks and run parameters, SNP-level counts, DNA truth) are not available, so those parts of the analysis rest on the retained post-QC grid and source defaults.

Key findings

  1. Data package: 24/24 files match the handoff manifest by SHA-256 (1,358 MB in total); release tag cloud-review-data-2026-11-04.
  2. Pinned upstream source: 12/12 files match at commit e8305ea (expected e8305ea; pyproject 0.3.5).
  3. AnnData: 3,460 cells × 25,337 bins (100 kb) over 22 autosomes; raw non-zeros 61,621,243, X non-zeros 61,076,659; no explicit stored zeros ({'X': 0, 'layers/raw': 0}).
  4. MuData: 3,460 cells, cell set equal to the AnnData (True), order equal (True); clusters used: wnn_leiden_0.3 with sizes 0: 1,286, 1: 833, 2: 603, 3: 556, 4: 182.
  5. Allelic matrices: 3,460 barcodes; AT = HA + HB exactly (True), non-negative (True), integer-valued (True); barcode sets equal but column order differs from the AnnData, so joins are by name.
  6. Frozen 300-cell panel: 300 cells, all in the AnnData (True), {'low': 100, 'mid': 100, 'high': 100} per coverage tercile.
  7. Stage availability: 2 available, 2 reconstructed from the pinned source, 5 not available; 1,103 autosomal bins removed by the bin filter have unknown contents.
  8. 5 historical uncertainties are recorded, including 11 cells whose saved X is not reproduced (17 cell-bins zero historically) and an environment that cannot be resolved as recorded.

Question and why it matters

Question. Which exact files, versions, dimensions and units did the review use, are they what the handoff manifest says they are, are the matrices aligned with each other, and which preprocessing stages are available or missing?

Why it matters. Every later result (experiments 01–07) is only interpretable if the inputs are byte-identical to the released package and the pinned source, and if their units are understood. The recommendation’s stage 0 and its blocked or skipped items (Numbat-multiome and Alleloscope comparisons, a raw-count model that includes QC-removed bins, SNP-level allelic likelihoods) depend on exactly which stages are missing, listed here. This experiment does not test any scientific claim: it checks identity, alignment and availability.

Inputs

  • Handoff manifest. research/2026-11-04-cloud-review-handoff/DATA_MANIFEST.json and PACKAGE.json: 24 data files, 12 upstream source files with expected SHA-256 hashes.
  • Data package cloud-review-data-2026-11-04 (root from PYEPI_SCIENTIFIC_ROOT): pyepi_results/count_matrix.h5ad, binned_genome.csv, hg38-blacklist.v2.bed, integration-story/data/integrated.h5mu, aligned_matrices/{HA,HB,AT}.parquet, genome_pool files and others listed below.
  • Upstream source. pyEpiAneufinder checkout (via PYEPI_SCIENTIFIC_PACKAGE), pinned to commit e8305ea.
  • Frozen panel. research/2026-10-29-low-coverage/shared/cells.tsv (300 cells, 100 per coverage tercile).
  • Other experiments’ summaries. Experiment 06 alignment checks and experiments 01/02 counts are read from their summary.json, so run this experiment last.
  • Not available. Source fragments or BAM, pre-QC counts, QC masks and run parameters, SNP-level counts and phase blocks, independent DNA truth (see stage availability).

Method

  1. Recompute SHA-256 of every file in the manifest and compare with the recorded hash.
  2. Recompute SHA-256 of every pinned upstream file, and read the checked-out git commit.
  3. Read AnnData and MuData dimensions, cell sets and order, and cluster sizes; check that the frozen 300-cell panel is contained in the AnnData and balanced across terciles.
  4. Record units (what X and the raw layer mean, what AT counts) and the alignment checks of experiment 06.
  5. List what is available, reconstructed or missing for each preprocessing stage and what each missing item blocks.
matches_manifest = (sha256(file) == manifest.sha256)
cell_set_equal  = set(mudata.obs) == set(anndata.cells);  cell_order_equal = identical order

Historical uncertainties

  • 17 cell-bins zero in saved X but large in every tested rebuild environment (experiment 01); historical environment unrecorded.
  • Historical run parameters (minFrags, thresholds, k for the production per-cell run) not recorded in the package; source defaults assumed.
  • Recorded handoff environment lists numpy 1.24.4 with scikit-misc 0.5.2, whose metadata require numpy >= 1.26.4: that environment cannot be resolved as recorded (installed here with --no-deps).
  • Pileup tool/version, UMI/read mode, SNP list and genotyping thresholds behind HA/HB/AT unknown.
  • 1103 autosomal bins removed by the bin filter; their contents are unknown without pre-QC counts.

Sensitivity

Not applicable: this experiment makes no estimate. Byte identity is binary.

Limits and alternative explanations

  • Matching hashes show the files are those that were released; they do not show that the release itself is correct or complete.
  • Identity of the upstream source does not establish that the historical run used that source or its defaults; run parameters were not recorded.
  • The recorded handoff environment (numpy 1.24.4 with scikit-misc 0.5.2) cannot be resolved as recorded; it was installed here with --no-deps.
  • Alignment checks cover coordinates, barcode sets and units; they cannot detect an upstream error in SNP selection, phasing or pileup, which are unrecorded.

What the evidence supports

Supports

  • The data package and pinned source used for all experiments are byte-identical to the handoff manifests.
  • The matrices can be joined safely (by name for allelic data), with units documented.
  • Missing stages are recorded so that blocked comparisons are traceable to specific missing inputs.

Does not support / cannot tell

  • That the released data or the historical run were correct, or that the historical environment matches the one used here.
  • Anything about copy number: this is an identity and availability check.
  • Any method comparison that needs fragments, pre-QC counts, SNP-level counts or DNA truth.

Decision impact

Supports recommendation stage 0 (persist run parameters, pre-filter grid, QC masks and GC diagnostics with every run) and explains why Numbat-multiome, Alleloscope and a raw-count model that includes QC-removed bins are listed as blocked: each depends on inputs marked missing here.

Next checks

  • Obtain fragment files, pre-QC counts and QC masks, and the historical parameter_configuration.txt.
  • Obtain SNP-level allele counts with phase-set IDs and the pileup and genotyping settings behind HA/HB/AT.
  • Resolve the recorded environment (numpy and scikit-misc versions) and add independent DNA truth for at least one sample.
