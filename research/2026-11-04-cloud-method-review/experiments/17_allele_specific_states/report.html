Bottom line

Combining depth with alleles separates regions that behave like simple allele-specific dosage changes from regions whose depth change has no matching allelic pattern; the deep chr7 dips belong to the second group.

Key findings

  1. Baseline variability used as depth uncertainty: σ_A = 0.391 (log scale, flank-relative) and 0.462 (genome-relative), from 226 uncalled random windows. Allelic null: median ĥ 0.520, spread τ = 0.026.
  2. chr7 saved windows (L 0.13–0.34, ĥ 0.500–0.545): MAP states chr7_8.3_10.7 → none, chr7_51.4_53.5 → none, chr7_67.4_70.0 → none, chr7_70.0_73.3 → none; 4 of 4 flagged 'no modelled state fits'.
  3. Called short losses: 22/46 fit a modelled state; MAP one-copy loss 6, homozygous loss 0, none 40.
  4. Called short gains: 20/21 fit; MAP gain1 0, gain2 2, amp 3, none 15.
  5. Literature controls (k = 0.6): 9p21_hemizygous_zone_approx: none (fits); MYC_8q24: gain1 f=1.0 (fits); 19q13_qter: none (fits); 5q13_qter: gain1 f=1.0 (fits).
  6. Adding alleles changes the depth-only MAP type in 80 of 378 regions.

Question and why it matters

The user asked to move from depth to the allelic signal, use the model that suits each modality, and combine them to identify major and minor haplotypes. This experiment scores explicit allele-specific states against a region's depth level and major-haplotype fraction, each with its own likelihood and its own empirical null, and reports when no simple state explains both. It is the prototype for the evidence layer in recommendation.md.

Inputs

  • Depth: experiment 04 region_contrasts.tsv (raw counts, 3,460 cells): 378 regions (random: 300, called: 67, saved: 7, literature: 4).
  • Alleles: experiment 10 region_estimates.tsv (group all, empirical ρ = 0.0038): phase-agnostic ĥ with profile interval.
  • Per-cell zeros: experiment 04 (cells expected to have ≥ 5 target fragments that observed 0).
  • Not available: SNP-level phase sets (ĥ is phase-agnostic), mappability, independent truth; MCF10-A baseline assumed 1:1.

Method

  depth   L_obs  = raw-count rate ratio target/flanks (rr_flank_raw, exp 04); for broad literature
                   loci without flanks, target/genome density (rr_genome_raw).
                   log L_obs ~ Normal(log L_exp, sigma_A^2), sigma_A = robust SD (1.4826 MAD) of
                   log L over UNCALLED random windows (exp 04/08): the realistic regional
                   baseline (accessibility/mappability) variability; sampling SE is negligible.
  allele  h_obs  = phase-agnostic major-haplotype fraction (beta-binomial MLE, group 'all',
                   empirical rho; exp 10), folded to >= 0.5, with SE from its profile interval.
                   h_obs ~ Normal(m, se^2 + tau^2),  m = max(0.5 + k (h_exp - 0.5), h_null_median)
                   tau = robust SD of h_obs over uncalled random windows; h_null_median absorbs
                   the folding bias at balance; k = allelic attenuation (not identified here; grid
                   1.0 / 0.6 / 0.4; exp 06/10/13 measured strong attenuation at published gains).
                   Regions with < 3 bins carrying AT contribute no allele likelihood (missing, not balanced).
  cells   (homozygous-loss states only) among cells expected to have >= 5 target fragments
                   (exp 04), zeros ~ Binomial(n, f + (1 - f) p0), p0 = 0.005.
States: event type x cell fraction f in {0.1, 0.2, ..., 1.0}, diploid baseline 1:1 = level 1.
  none (1:1)                    L = 1,             h = 0.5
  loss1  1:0 in f              L = 1 - f/2,       h = 1 / (2 - f)
  homdel 0:0 in f              L = 1 - f,         h = 0.5
  cnloh  2:0 in f              L = 1,             h = (1 + f) / 2
  gain1  2:1 in f              L = 1 + f/2,       h = (1 + f) / (2 + f)
  gain2  2:2 in f              L = 1 + f,         h = 0.5
  amp    4:1 in f              L = 1 + 1.5 f,     h = (1 + 3 f) / (2 + 3 f)
Prior: uniform over event types (0.5 on none to reflect that most regions are not events is a
sensitivity), uniform over f. Posterior per type; MAP state; posterior-predictive fit check:
depth z = (log L_obs - log L_exp)/sigma_A and allele z under the MAP state; |z| > 2.5 for the MAP
flags 'no modelled state fits' (unmodelled baseline effect or state). Also reported: the best
fit if the depth term is dropped (allele-only) and if alleles are dropped (depth-only).
Major/minor relative copies: posterior means of a = major, b = minor copies averaged over cells
(population average under each state), with 90% credible intervals.

Limits and alternative explanations

  • The state grid assumes a 1:1 diploid background and population-average mixtures; real samples can have other baselines, several subclones or allele-specific accessibility.
  • k is not identified. Published MCF10-A gains (MYC, 5q) show strong attenuation, but their true allele-specific states are not known here, so k cannot be calibrated.
  • σ_A comes from random windows, which can contain events and are not neutral truth.
  • Depth and allele observations share fragments; treating their likelihoods as independent overstates certainty somewhat.
  • ĥ is phase-agnostic and pooled over bins; mirrored events in different cells cancel.
  • Ascertainment: heterozygous sites are selected in the same sample. In a clonal hemizygous region (e.g. the published 9p21 loss) truly lost-heterozygosity sites are not selected, so the remaining sites look balanced and the allele term pulls toward 'none'. Experiment 06 found the expected signature there (0.20× selected-site observations per fragment). A state model needs an explicit site-density term, or a matched normal, before balanced alleles can count against a loss.

What the evidence supports

Supports

  • Reporting major/minor relative copies with credible bounds per region, with the modality contributions shown separately.
  • Flagging depth changes that no modelled dosage state explains given the observed alleles.
  • Using allele evidence to change or confirm a depth-only call.

Does not support / cannot tell

  • Absolute copy number or verified haplotype identity (phase is not verified).
  • A calibrated attenuation k; calls that change with k remain unresolved.
  • Distinguishing accessibility from dosage when alleles are balanced and depth is moderately reduced.

Decision impact

This is the concrete form of rank 1 in method_comparison.tsv (evidence layer) extended with rank 5 (joint depth–allele evidence): modality-specific likelihoods, empirical nulls for each, and an explicit 'no state fits' outcome. To become a method it needs a calibrated k (SNP-level, phase-aware counts) and an external baseline for σ_A.

Next checks

  • Calibrate which allele source (phase-agnostic or HMM-oriented) to use on samples with DNA-defined allele-specific states.
  • Add a selected-site-density likelihood (AT per fragment vs genome) so that LOH-driven ascertainment loss counts as evidence for loss.
  • Replace phase-agnostic ĥ with the HMM-oriented major-haplotype fraction from experiment 16 when available.
  • Estimate k on samples with DNA-defined allele-specific states.
  • Run per cluster to expose subclonal or mirrored events.
