# validation/

This directory holds two kinds of content:

- **Evidence** — screenshots, JSON/CSV outputs, and browser-test result
  files, generated by running a specific test script and reproducible from
  it. Not hand-edited.
- **Reports** (`REPORT.md`, `REVIEW.md`, `HANDOFF.md`, `PLAN.md`) — the
  human-written interpretation of that evidence. These are the authoritative
  documents to read first; see [`docs/VALIDATION.md`](../docs/VALIDATION.md)
  for the map from feature area to report.

## Subdirectories

- **`hatch-merge/`** — evidence and handoff for the exploratory hatch-layer
  and adjacent-segment merge feature.
- **`integration-freeze/`** — evidence and report for the segmentation tab's
  scroll-triggered chart loading and the responsiveness investigation behind
  it.
- **`integration-review/`** — evidence and review for the alternative flank
  view and paired-cell bootstrap.
- **`reload-recursion/`** — evidence and report for session restore across
  recursion-depth changes.

## Root-level files

Top-level screenshots (`cohort.png`, `explorer.png`, `manual.png`,
`experiment-*.png`, `width-series.png`, `integ0*.png`) and result files
(`*-results.json`, `*.log`, `VALIDATION_REPORT.md`) are evidence for the
main X-experiments/manual-segmentation/integration walkthrough, produced by
`tests/browser_experiments.cjs`, `tests/browser_workflows.cjs`,
`tests/browser_integration_rendering.cjs`, and related scripts — see
[`tests/README.md`](../tests/README.md) for which script produces which
file.
